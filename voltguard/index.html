4. Testing Protocol

  1. Multimeter test: Verify resistance between silicone layer and outer fabric — should read >10MΩ
  2. Visual inspection: Check for gaps, thin spots, incomplete coverage
  3. Wash test: Machine wash one unit 10 times, re-test resistance
  4. Contact test: Touch silicone layer on 9V battery terminals — should feel no current
  5. High-voltage test (optional): Use insulation tester at 1000V
